# Tayyor statik saytlar

`static/<nom>/` — boshqa loyihada yig'ilgan tayyor sayt (index.html va fayllari). Deploy paytida
`scripts/build-all.js` uni o'zgarishsiz `<nom>.<domen>` ga chiqaradi.

- `suhrob-rayhona` — github.com/alyorbek-tukhtasinov/suhrob-rayhona (Vercel'dan ko'chirilgan).
  Yangilash: o'sha repoda `npm ci && npx vite build`, so'ng `dist/` ichidagilarni shu papkaga nusxalash.
